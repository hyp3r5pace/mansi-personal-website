# Working agreement (read every session)

1. **At the start of every session, read `HANDOFF.md`** before doing anything
   else. It holds the full project context: what the site is, the architecture,
   the recurring Behance-import flow, live integrations, parked work, and the
   gotchas/things-that-failed. Do not relearn what's already documented there.

2. **After every successfully completed task or feature, update `HANDOFF.md`.**
   Append/update concisely:
   - **What was done** — the task and the outcome (and any new files/config).
   - **What was tried that failed** — dead ends, gotchas, and the fix, so the
     next agent doesn't repeat them.
   Keep it brief and de-duplicated; fold new gotchas into the existing
   "Gotchas & things that failed" section rather than sprawling. Commit the
   `HANDOFF.md` update alongside the work.
